# 03 人物写真からキャラクターシート（三面図）

## 入力

- image1: `refs/ref-01.png`

## Generic instruction

```text
Make a character sheet of the person in image 1: front view, side view, and back view standing in a row, on a plain white background.
```

## 見るもの

- 正面・側面・背面の3体が並んでいるか
- 3体で顔・髪・服・体型が一致しているか
- 側面・背面の推定の妥当性
- 縮尺が揃っているか
