# 0002 スキルは無印と軽量版の2本立てにする

- ステータス: 採用
- 日付: 2026-09-23

## 背景（Context）

プロンプトを組み立てる LLM には2種類ある。

- フロンティアモデル（Claude Code / Codex 等）。分岐・確認・説明を含む長い指示を扱える。通常のスキル（`SKILL.md`）として配布する
- ComfyUI 等の LLM ノードで動かすローカルの汎用 LLM。実用になるのは 27B 級で、8B 以下は LLM としてうまくいかない。system prompt として貼れる形が必要で、分岐が多い指示は苦手

1本の SKILL.md で両方に対応させると、フロンティア向けの分岐と説明がローカル LLM の system prompt には重く、逆にローカル向けに削ると無印が痩せる。

## 決定（Decision）

- **無印（`SKILL.md`）** をスキルの正とし、フロンティアモデル向けに書く。プラグインとして読まれるのはこのファイルだけ
- **軽量版（`SKILL-lite-<mode>.md`）** を同じフォルダに別ファイルとして置く。27B 級の汎用 LLM に system prompt としてそのまま貼る前提で、frontmatter を付けず、単発変換（入力=ユーザーの雑な依頼、出力=最終プロンプトのみ）を契約にする
- `<mode>` は操作単位（`t2i` / `i2i` 等）。小さい LLM に分岐を持たせないため、モードごとに別ファイルにする。公式の prompt enhancer も T2I / I2I でモデルを分けている
- 軽量版は無印の方針（肯定形の記述・保持指示・参照タグ・RGBA ラッパー等）から導出する。無印を変えたら軽量版も見直し、無印の本文から軽量版の存在と用途を指す
- 軽量版はサイズ・アスペクト比・ステップ数をプロンプトに含めない。ワークフロー側の設定に委ねる

## 影響（Consequences）

- 構造検証に「軽量版が frontmatter なし・単発変換の契約・無印と整合」を含める
- 軽量版はプラグイン機構では配布されない。ユーザーはリポジトリからファイルをコピーして LLM ノードの system prompt に貼るか、system prompt を config から読むノード向けに `scripts/make_llm_config.py` で config を生成する。README の導入方法にその旨を書く
- モードが増える（例: RGBA 専用、動画モデルの i2v）と軽量版ファイルも増える。1プラグイン内で散らかり始めたら `lite/` サブフォルダへの移動を再検討する
